# 性能分析与整包更新（0.5）

2026-11-09 用户明确：热更新指“不重新安装修复代码”，先做性能分析、整包更新，不确定的暂缓。本轮实现 Android；iOS、鸿蒙平台分支未接入这套 Android 安装流程。

## 本机性能分析

长按首页标题进入实验台，点击“本机日志与性能”。保留原有轮转日志、手动导出、CPU/PSS/堆、主线程抽样、首次绘制、固定路由 HTTP 统计和系统退出记录。

新增最近最多 20 个资源样本的均值/最大值，以及固定操作的次数、异常次数、平均/最大耗时和 ≥16ms 次数：

| 操作 | 范围 |
| --- | --- |
| session_save | 会话序列化与同步 SharedPreferences commit |
| usage_record / usage_ack | 用量队列写入/已确认记录移除，包括锁等待和写盘 |
| app_label | 首页应用名称缓存未命中时的系统查询 |
| home_render | 首页每秒刷新执行耗时，不包含随后系统布局/绘制 |
| update_check / update_download / update_verify | 更新清单请求、APK 流式下载、下载后及安装前校验 |

统计仅保存在本进程内存，随现有诊断手动导出；不上传、不新增常驻服务或运行时 SDK。≥16ms 是操作耗时计数，不是掉帧判定；资源窗口最多约十分钟，取决于进程是否实际运行采样。计数中的失败表示操作抛出异常，不替代业务拒绝统计。

首页应用名称缓存最多 32 项、有效期 60 秒，回到首页时清空，减少每秒重复 PackageManager 查询。会话仍同步保存成功后才授予延期，未改成异步写盘。

### 可重复采样

在同一测试设备、同样规则和网络下，分别记录：①首页停留 60 秒；②游戏计时 3 分钟；③提醒、两次延期及第三次审批；④答错换题/答对；⑤断网后恢复补报。记录版本、场景、开始/结束时间与是否冷启动，场景结束手动导出诊断。比较前后版本时使用独立测试设备或备份，不清空真实孩子的周期数据。

```powershell
.\tools\capture-performance.ps1 -Adb '已有 SDK/platform-tools/adb.exe' -OutputDirectory '本机新目录' -Serial '设备序列号' -Samples 3 -IntervalSeconds 30
```

脚本只读取本 App 的 package/meminfo/gfxinfo，不 force-stop、不重置帧统计、不改规则。CPU 和关键操作指标从 App 手动导出；gfxinfo 主要反映本 App 窗口，不能当作悬浮窗全程或其他游戏帧率。模拟器不能替代真机耗电、温升、厂商后台策略和真实游戏流畅度验收。未取得设备基线前不宣称优化百分比。

## 手动整包更新

长按首页标题 → “手动检查整包更新” → 检查 → 下载 → 校验并确认安装。第一次安装权限未开时，用户自行进入系统设置授权，返回后再次手动点击安装；最终由 Android 系统安装器确认。取消或失败保留当前应用。没有定时联网、后台自动下载、强更、静默安装或原生代码补丁。

下载为后台单任务流式写入，连接超时 10 秒、读取超时 15 秒。失败不保留可安装的半包，点击重试会重新完整下载，不支持断点续传。完整文件和候选清单存在应用私有目录，进程重启后重新校验再恢复；清理成功后最多保留当前候选和一个先前 APK。缓存文件只通过不可导出、只读、精确 URI 授权的 ContentProvider 交给安装器。

安装前检查游戏周期、倒计时、答题和已保存的游戏周期状态；本轮未完成或无法读取状态则暂缓安装。没有自动更新弹窗打断游戏。下载仅由用户点击发起，流量策略尚未配置；要先自行连接适当网络。现有实验台尚无正式家长身份验证，不作为生产家长入口验收。

### 更新清单与构建

默认 `UPDATE_MANIFEST_URL` 留空；未选择正式域名、分发渠道或生成生产私钥。Release 固定读取构建参数；Debug 额外显示调试地址输入框，值仅存在本机私有配置。

```powershell
.\gradlew.bat :app:assembleDebug '-PquizgateVersionCode=7' '-PquizgateVersionName=0.5.1' '-PquizgateUpdateManifestUrl=https://updates.example.com/quizgate/update.json'
# 以上仅演示参数；正式 Release 必须另行使用确认的发布签名流程。
.\tools\make-update-manifest.ps1 -Apk '已签名 APK 的路径' -ApkUrl 'https://updates.example.com/quizgate/app.apk' -Output '本机输出/update.json' -Notes '本次修复说明'
```

`make-update-manifest.ps1` 复用已有 SDK 的 aapt 和 PowerShell SHA-256，不安装依赖、不签名、不上传。清单必须与 APK 同源（协议/主机/端口相同），部署在无重定向、无需孩子端令牌的静态 HTTPS 地址。示例域名仅为占位。调试 HTTP 只允许网络安全配置已有的 localhost、127.0.0.1、10.0.2.2、192.168.1.76，并需脚本加 `-AllowDebugHttp`；Release 不接受 HTTP。

```json
{
  "schemaVersion": 1,
  "versionCode": 7,
  "versionName": "0.5.1",
  "minSdk": 26,
  "sizeBytes": 123456,
  "sha256": "由脚本从真实 APK 生成的 64 位小写 SHA-256",
  "apkUrl": "https://updates.example.com/quizgate/app.apk",
  "notes": "本次修复说明"
}
```

清单上限 16 KiB、说明 4000 字符、APK 200 MiB；数值字段严格要求整数。不接受带账号、查询参数或片段的 URL，不跟随重定向，不携带设备登录令牌。校验实际大小、SHA-256、包名、清单与 APK 的 versionCode/minSdk，以及当前已安装应用和候选包的当前签名集合。只接受更高 versionCode，当前方案不支持签名密钥轮换。不能用 Debug 包给正式签名包升级。APK 签名最终由系统安装器验证。

正式签名与备份、分发渠道/地址、自动检查/下载和 Wi-Fi 策略、强更规则均待确认；代码热补丁继续暂缓。

## 验证边界

更新单元测试覆盖清单字段、协议/同源限制、版本/包名/签名决策，以及真实本地 HTTP 下载、大小/摘要不符、半包删除、重定向拒绝与清单限长；HTTP 下载测试数据不是 APK，不能代替 Android 安装验证。性能测试覆盖异常和返回值不变、固定标签及采样窗口上限。

本轮复用已有轻量 JDK/SDK 和 Gradle 缓存，只新增测试依赖 org.json；不新装 Android Studio、NDK 或系统镜像。本执行环境启动现有 AVD 返回硬件加速不可用，当前没有 ADB 设备，因此尚未验证系统安装器、跨版本数据/无障碍权限保留、进程重启恢复的 Android 实机表现及真机性能。构建和测试结果以本次交付记录为准。

本轮 104 项 JVM 测试通过（原有 86 项加 18 项更新/性能测试），Debug 和未签名 Release 构建成功，Release 必要 lint 通过；两个同签名 Debug 测试包通过 apksigner 校验。完整 Debug lint 仍有原有 `QUERY_ALL_PACKAGES` 权限提示：本产品依赖已获用户同意的完整应用清单，本轮不删除该权限或屏蔽此规则；正式渠道及其权限审核未确认。Windows 沙盒默认临时目录无法执行测试所需的文件重命名，本轮将 JVM 临时目录改到工作区后全部通过，未改动写盘正确性代码。

原生安装 API 和签名依据：[Android 安装权限](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls())、[应用签名](https://developer.android.com/studio/publish/app-signing)、[SigningInfo](https://developer.android.com/reference/android/content/pm/SigningInfo)。
